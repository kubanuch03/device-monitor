Device Monitor

Пока ни одного устройства

Добавьте камеру, домофон, коммутатор или сервер — сервис начнёт проверять его доступность и покажет, когда он пропал.

Новое устройство

Группа, в которой устройство будет показано. Новое имя создаёт новую группу.

Можно вставить ссылку целиком — порт и путь разберутся сами.

Устройство считается живым, если открыт хотя бы один из них.

Куда открывать на устройстве. По умолчанию корень — /.

У камер объекта пароль обычно общий — заведите его один раз в настройках точки.

Нужен для сбора сведений с устройства (модель, серийник, прошивка).

Нужен, когда до устройства браузер сам не дойдёт — например, оно за туннелем и проброшено на локальный порт. Пусто — открывается обычный адрес.

Как источник называется в go2rtc объекта. Заполняется только у камер — тогда у устройства появляется кнопка «Смотреть». Адрес самого go2rtc задаётся у точки.

Новая точка

Для объектов без прямого маршрута — через SSH-туннель ssh -D. Пусто = прямой доступ.

Адрес go2rtc на сервере объекта. Браузер не умеет RTSP сам — поток переупаковывает go2rtc, а дашборд только показывает его плееры. Пусто = видео у точки нет.

Общая учётка объекта. Устройства берут её, только если у них это включено явно.
